A HAX site is an outline of pages, and you can reshape it like one.

Try it
------

1.  Type "outline" in Merlin's search box and pick Edit site outline.
2.  Drag this page somewhere else, rename it, or nest it under another page.
3.  Add a page: Create a new page (Ctrl Shift 3), then write in it.

The menu, the Next and Previous links and the breadcrumb follow the outline on their own.

Why an outline
--------------

Courses, handbooks and portfolios are all outlines. HAX stores yours in one readable file, `site.json`, in the open [JSON Outline Schema](https://github.com/haxtheweb/json-outline-schema), so a site can be moved, versioned with git, or built by an AI agent and still edited by a person.
