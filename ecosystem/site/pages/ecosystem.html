Start building

Two ways in. Same sites, same blocks, and everything stays editable by people.

In a terminal

Install the HAX CLI once, then make a site or a web component with DDD, translations and accessibility checks built in. Needs Node.js.

Or skip the menu:

The CLI: haxtheweb/create

With your AI agent

Paste this into Claude Code, Warp or any coding agent. PRAW gives it HAX's rules and skills, so what it builds stays something a person can open and edit.

Rules and skills: haxtheweb/praw. Connecting an agent to a running site: haxtheweb/haxcms-mcp (pre-release).

No install at all: try the live HAXcms demo, or put the magic script on any page.

Where the code lives

create
The HAX CLI: sites, components, audit and publish.

praw
The brain: rules, skills and this site.

haxcms-nodejs
HAXcms on Node.js. Runs every site the CLI makes.

haxsite
A plain HAXsite to fork and publish.

haxcms-php
HAXcms on PHP, the same API contract as Node.

haxcms-mcp
MCP server for HAX sites. Pre-release.

webcomponents
Every element, theme and the DDD design system.

issues
One issue queue for the whole ecosystem.
