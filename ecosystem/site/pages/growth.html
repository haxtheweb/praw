The data

Everything above comes from the growth data layer in PRAW, published as open JSON (Apache-2.0) with the other hax.cloud datasets: repositories, themes and elements over time, which elements depend on which, what each theme and element loads, and monthly series. Start at the dataset catalog or the OpenAPI description; how the numbers are made is in PRAW.

Agents in the browser can ask this page directly: where the browser supports WebMCP, the drawing offers read-only tools for a series, a theme's cost with and without cache, an element's dependencies and a visitor's journey.
