How it works

  1. Detect. build.js watches the page for custom elements that are not defined yet.
  2. Look up. It finds each tag in wc-registry.json, which the ubiquity build writes for every element HAX publishes.
  3. Import. It imports that element's module from the CDN, unbundled, so a page only loads the elements it uses.
  4. Hydrate. The element defines itself and the tag comes alive.

This is how every HAX site, HAXcms and the HAX editor load so fast: small ES modules over HTTP/2 and 3, fetched on demand, cached by the browser and shared across pages. A HAXsite runs the same build.js from its own copy, and falls back to the CDN.
