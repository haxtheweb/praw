HAXcms Dashboard

How to Create an Online Course in HAXcms

Prerequisites

  • Ensure you have access to the HAXCMS dashboard.
  • Be ready with a course name for your new online course.

Having these prerequisites will make your course creation process smooth and efficient.

Access the Online Course Creation Tool

From the HAXCMS dashboard, locate and click the Online Course option. This will open the course creation interface where you can start building your new course.

Name and Create Your Course

Enter your desired course name (for example, HAX100) in the provided field. You can either press Enter on your keyboard or click the Create Site button to proceed. The system will begin creating your course, indicated by a progress bar and a hat icon.

Review and Manage Your New Course

  • Once your course is created, you'll see a progress bar fill up.
  • Choose to stay on the dashboard to review all your sites, or open the new course in a new tab.
  • Observe your dashboard tray filling up with the new course site.

This area allows you to manage multiple courses efficiently.

Explore Course Management Options

  • Click the three dots next to your course site for more options:
  • Copy the space to duplicate your course.
  • Download the space as a zip file for backup or offline use.
  • Create a template from your course after customizing settings, themes, and content. This lets you reuse the structure for future courses.
  • Archive the course if you want to remove it from the active dashboard but keep it stored.

Access and Edit Your New Course

Click on the course site (e.g., HAX100) to enter the course editing environment. This is where you can begin adding content, selecting themes, and adjusting settings to tailor your course as needed.

Verification

  • Check that your new course appears in the dashboard tray.
  • Ensure you can access the course editing environment and see the customization options.
  • Test downloading or templating features to confirm full access to management tools.

If all these steps work, your course is set up and ready for further customization!

Prerequisites

Before diving into your HAX site settings, ensure you have administrator access to the content management system. This will allow you to view and modify all available options for site customization.

Access the Site Settings Panel

To begin customizing your HAX site, navigate to the site settings area. Look for the icon resembling a house with a pencil. Clicking this will open the site settings dashboard, providing access to all configuration categories.

Customize Appearance and Structure

  • Theme & Appearance: Change the site's visual theme and overall look to match your brand or preferences.
  • Structure: Use the site outline to organize your content and review the structure of your pages.

Leverage Reports and Insights

Utilize the Reports section to gain valuable insights into your content. This area is actively being developed, but it already offers tools for content search, accessibility audits, and discovering how media is used throughout your site.

Explore the About Section and Shortcuts

  • About HAX: Learn more about the HAX project and how to get involved.
  • Keyboard Shortcuts: Discover shortcuts to optimize your workflow within the system, including links to tutorials and API documentation.

Manage Files and Data Views

Access the Files section to view and manage all uploaded files on your site. Use Views to slice and visualize your data in different ways, making it easy to embed insights or utilize data dynamically throughout your site.

Configure Features and Editor Modes

  • Features: Toggle core features of the HAX system on or off. For example, disable the outline designer, page addition, or deletion as needed for your team.

  • SEO Settings: Ensure your site is compliant with Google, Microsoft, and other search engines, as well as AI agents.

Verification

After making your changes, review your site's title, homepage, and other details to confirm that all customizations have been applied successfully. Regularly revisit the site settings to take advantage of new features and improvements as HAX continues to evolve.

Prerequisites

  • Access to HAXcms site dashboard
  • Administrator privileges

Access the System Settings

  • Current vs. latest HAXcms version

Configure Themes

  • Enable/disable available themes

The Media section allows you to define policies for image uploads. Set restrictions on image size, quality, and acceptable file formats to ensure media consistency and performance across your HAXcms sites.

  • Define maximum image size and quality

  • Upcoming integrations: AI, YouTube
  • Future expansion planned

  • Refresh dashboard to verify updates

  • Consult status page for error messages

Create a New Page

How to Create and Manage Pages in HAX

Prerequisites

Before you begin, make sure you have access to HAX and are logged into your account. Familiarity with basic navigation in HAX will help streamline the process.

  • Active HAX account
  • Basic understanding of the HAX interface

Locate and Use the Add Page Button

Find the blue Add Page button in the top corner of your HAX workspace. Click this button to start the process of creating a new page.

  • The Add Page button is easily visible and provides quick access to page creation features.

Create a New Page and Set Its Title

After clicking Add Page, a search bar appears. Here, you can type your desired page title. For example, entering Given Text will set this as your new page's title. Alternatively, pressing Enter without typing will create a page titled New Page.

  • Use the keyboard to navigate options such as duplicating the current page or creating a blank one.
  • Select Create Blank Page to start from scratch.

Understand and Edit the Page Slug and Title

The page slug (the URL segment after your site name) automatically matches your page title, e.g., Given-Text. Both the title and slug can be changed later if needed. To edit them, click Select to Edit Page Details in the page's content area. Here you can:

  • Change the page title
  • Edit the slug under Advanced
  • Adjust publishing status
  • Lock the page or move it in the outline
  • Save changes when finished

Add Content and Use Slash Commands

In the page editor, you can start adding content such as text, images, or videos. Use slash commands (e.g., /image) to quickly insert media and other elements. If you decide to change the page title while editing, simply access the page details as described above.

Save and Confirm Your New Page

After making your changes, click Save to update the page. The new title and slug will be reflected immediately, and your content will be preserved.

Add Pages Using the Outline Actions

Another way to add a page is through the Outline Actions menu. When working in the outline, click Add File Page to create a new page at your current location in the hierarchy. The process is similar to adding a page from the top menu, and you can press Enter to quickly create the page.

  • Pages added here can be organized as child pages under existing pages.

Organize Pages in the Hierarchy

Pages created via Outline Actions appear as child pages under the selected parent. This makes it easy to build structured content and maintain a clear hierarchy. You can move pages around as needed to reflect your desired organization.

Verification

To verify your new page, check the outline and the site URL to confirm the correct title and slug. Ensure your content appears as expected and that the page is in the intended location within the hierarchy.

  • Review the outline structure
  • Click the page to preview its content
  • Double-check the URL for accuracy

Reorder & Organize Pages

How to Reorganize Your Site Structure in HAX

Prerequisites

  • Access to your site in HAX
  • Basic familiarity with the HAX interface

Before starting, make sure you have editing permissions and are logged into your HAX site workspace.

Use Outline Actions for Quick Edits

To quickly modify your site's structure, use the Outline Actions pencil icon located beside the active page. This menu lets you:

  • Add a page under the current one
  • Move pages up or down relative to siblings
  • Indent or outdent pages to change their hierarchy
  • Jump a page to a new location

These actions are ideal for making immediate, in-context changes without leaving your current workflow.

Move and Indent Pages

To change page hierarchy or order:

  1. Click Outdent to move a page out of its parent group.
  2. Use Move Up or Move Down to rearrange the page among its siblings.
  3. Switch to the previous parent page if needed, and use Indent to nest it under a different parent.

These quick actions let you reshape your outline efficiently. Indenting a new page under another makes it a child, while moving a parent page up brings all its children along.

Bulk Reorganization with the Site Outline and Structure Tab

For larger changes, open the Site Outline and Structure tab. This view offers:

  • A full overview of all site pages
  • Rapid addition of multiple pages
  • Drag-and-drop to move and nest pages in bulk
  • Planning and prototyping of large structures

This tool is especially useful for documentation sites, tutorials, or online courses where you need to craft or duplicate complex data structures.

Rename and Duplicate Pages Efficiently

Within the Site Outline and Structure tab, you can:

  • Double-click to rename multiple pages quickly
  • Tab to jump between items for fast editing
  • Move pages just like in Outline Actions, but with a focus on planned changes
  • Duplicate structures for reuse in courses or documentation

Once your changes are planned, click Save Outline. The system will confirm the number of new pages or changes before applying them. Upon confirmation, your site structure updates instantly, including any duplicated content.

Verification

After reorganizing, review your site outline to ensure all pages are correctly ordered and nested. Check that duplicated content appears as intended and that any new pages are in the right place. If needed, use Outline Actions for final tweaks.

Edit a Page

How to Edit a Page in HACS: Step-by-Step Tutorial

Prerequisites

  • Permissions: You need editing rights for the page you wish to modify.

Familiarity with basic navigation in HAX will help you follow these steps smoothly.

Open the Editor Panel

To begin editing, click the pencil icon at the top of the page. This action opens the editor panel, displaying the content blocks and page structure. You'll see the current source powering the page and a grayed-out section for settings.

Select and Edit Content Blocks

Click on any content block within the page body—such as a heading. The settings tab will open, allowing you to modify properties specific to that block. For example, selecting a heading reveals settings like text, lock status, and advanced developer options. Most users will focus on the Configure section for basic edits.

Edit Text and Block Type

  • Typing: Click into the text area and start typing or deleting as needed. The editing bar will disappear as you type and reappear when you pause.
  • Change Block Type: If you want to switch from a paragraph to another block type, use the tab provided in the editor panel.

This flexible editing lets you update content and structure easily.

Save Your Changes

Once you've made your edits, click the Save button to apply your changes to the page. This ensures all modifications are stored and visible to others with access.

Verification

Review the updated page to confirm your changes appear as intended. If necessary, repeat the steps to make further adjustments. Congratulations! You've successfully edited a page in HAX.

Adding Blocks

How to Use the Blocks Engine in HAX for Dynamic Content Creation

Prerequisites

Before you begin, ensure you have access to the HAX editor and are familiar with its basic text editing features. Having some experience with web content management will help you make the most of the blocks engine.

  • Access to HAX editing environment
  • Basic understanding of content blocks

Open the Blocks Menu

Click Edit in the HAX interface. If the blocks panel isn't already visible, select Blocks to access the full blocks menu. This panel displays all available content blocks for insertion.

  • Click 'Edit' to enter editing mode.
  • Select 'Blocks' if not already active.

Explore and Preview Available Blocks

Browse through the blocks panel to view popular and recent blocks. Hover over any block to see a preview of its appearance and function. You can also expand the panel to see all supported blocks—there are many options to choose from.

  • Hover over blocks to preview them.
  • Check the 'Recents' tab for blocks you've used before.
  • Expand the panel to explore all block types.

Filter and Select Specific Content Types

To find a particular block, use the Filter Content Type feature. For example, type video to see all video-related blocks, such as media playlists. This helps you quickly locate the exact block you need.

  • Click the filter and enter a keyword (e.g., 'video').
  • Review the filtered results for relevant blocks.

Insert a Block into Your Page

Once you've found your desired block, you can either drag it into the page or press the insert button to add it at the active cursor location. This places the block exactly where you want it in your content.

  • Drag and drop the block or click 'Insert'.
  • Position the block as needed in the content area.

Understand Block Structure and HTML Integration

Every block you insert in HAX is based on a sustainable HTML tag, ensuring compatibility and future-proofing your content. For example, a media playlist block uses a video player HTML element. While you usually don't need to edit the HTML directly, it's always accessible for advanced customization.

  • Blocks map to standard HTML tags.
  • HTML view is available for reference or advanced edits.

Reposition and Organize Blocks

To rearrange blocks, use the drag handle to move them within the page. Alternatively, hover over a block and use the move up or down options to adjust its placement. This flexibility helps you design layouts efficiently.

  • Grab the drag handle to move blocks.
  • Use hover controls to shift blocks up or down.

Save and Present Your Content

When you're satisfied with your block arrangement, click Save. Your changes will be applied, and the new blocks will be visible to your users. This final step ensures your content is updated and ready for presentation.

  • Review your changes.
  • Click 'Save' to apply updates.

Verification

After saving, review your page to confirm that all blocks appear as expected and function correctly. Test any interactive or media elements to ensure a smooth user experience. If needed, return to edit mode for adjustments.

  • Check block appearance and placement.
  • Test media playback and interactivity.

Slash Commands

Mastering Slash Commands for Efficient Content Editing

Prerequisites

  • Access to the content editor interface.
  • Basic familiarity with keyboard navigation.

Make sure you are logged in and have a document open for editing before starting.

Initiate Edit Mode

Begin by clicking the Edit button on your document. Then, click on any line where you want to insert content and press Enter. You should notice a faded message, such as type slash for quick actions, appearing on the new line.

Activate Slash Commands

Press the slash ( / ) key on your keyboard. This action brings up a contextual menu, similar to the options bar at the top, but directly where you are editing. The menu will display available quick actions.

Insert Content Using Slash Commands

  • To add a video player, type video after the slash and press Enter. The video element is inserted instantly.
  • For headings, type heading and select the desired level (e.g., Heading 3).
  • To create a bulleted list, type bulleted list and press Enter.

Slash commands enable rapid content creation without needing to use the mouse.

Explore and Navigate Available Commands

You can scroll through the slash command menu to view all available options. This allows you to discover additional actions and formatting tools without leaving your current workflow.

Keyboard Efficiency and Alternative Access

All slash commands are also accessible from the top options bar. However, using the keyboard keeps your hands in place and speeds up editing, especially for long documents. Embrace slash commands to streamline your writing process and minimize interruptions.

Verification

  • Check that the desired elements (video, heading, bulleted list) appear in your document after using slash commands.
  • Confirm that you can access all quick actions from both the slash menu and the top bar.
  • Practice using only keyboard shortcuts to maximize your editing speed.

Adding Video Blocks

How to Add Video to Your Page: Multiple Methods Explained

Prerequisites

Before you start, ensure you have editing access to the page. Prepare the video link (such as a YouTube URL) or have your local video file ready for upload.

Add Video Using the Media Block

  • Click Edit on your page to enter editing mode.
  • Open the blocks panel and search for Video under the Media category.
  • Select the Video block to add it to your page.
  • Update the source URL if you want to embed a different YouTube video.
  • Click Save to publish the changes.

Embed Video by Pasting a Link

  • While in edit mode, paste your YouTube link on a new, individual line.
  • The system will automatically detect the link and embed the video for you.

Insert Video Using the Slash Command

  • Type /video while editing to invoke the video insertion command.
  • Insert the video and update the URL to your desired video.
  • Add a title in the title field for accessibility and clarity.
  • Optionally, change the poster image to a custom thumbnail.

Customize Video Settings

  • Modify spacing around your video for better layout.
  • In the Advanced section, set up text tracks (captions/subtitles), choose if the video should start at the beginning, and add audio descriptive tracks if needed.

Create a Video Playlist

  • Drag one video on top of another to automatically create a playlist.
  • This feature is unique to videos and helps organize multiple clips in sequence.

Upload Local Videos or Use Screen Recorder

  • Use the Video block to upload a video file from your computer.
  • Alternatively, use the in-context screen recorder to capture and add a video directly.
  • Note: Screen recordings can result in very large files. Consider compressing before uploading.

Verification

After adding your video, preview the page to ensure the video displays and plays correctly. Test all customizations, such as titles, poster images, and playlists, to confirm they work as expected.

Working with Images

How to Work with Images in HAX: A Step-by-Step Guide

Prerequisites

  • Access to HAX editing environment
  • Some images or media files ready to use
  • Basic familiarity with editing a page in HAX

Start Editing the Page

Begin by entering edit mode on your page. This allows you to add and manipulate content blocks, including images, anywhere you need them.

Find and Select Image Blocks

  • Use the search bar to locate various image-related blocks.
  • Options include: Basic Image, Enhanced Image, GIF, Memes, Image Galleries, Timelines, Image Comparisons, Image Block Quotes, Cards, Self-Checks, and more.
  • Pick the block that fits your intended use.

Add Images via Drag and Drop

  1. Drag your image file from your computer toward the HAX page.
  2. Notice the interface highlights possible drop areas, such as the top search bar or specific sections of the page.
  3. Drop the image in the side panel to insert it at the bottom, or directly into your desired spot for precise placement.

Edit Image Properties

  • After insertion, the image appears as an enhanced image in the sidebar.
  • You can modify the image source, change alt text, add links, and style the image as a card with captions and citations.
  • Captions can be automatically filled in, making the content more accessible and descriptive.

Build an Image Gallery

  1. To create a gallery, drag one image onto another existing image on the page.
  2. The images will combine into a gallery block, allowing for grouped display and navigation.

Use the Top Bar for Advanced Image Options

  • Drag the image into the top bar for more options, such as:
  • Insert into the page
  • Link to the file
  • Set as page media
  • Upload only

This flexibility helps you manage how images are used and displayed.

Manage Uploaded Files in Site Settings

  1. After uploading, go to Site Settings and then Files to view all uploaded media.
  2. You can insert images later or copy direct links for reuse in different parts of your site.

What is HAX

HAX (Headless Authoring eXperience) is an authoring experience that enables rapid creation of fast, static, file-backed websites. It seeks to be the smallest possible back-end CMS to make the HAX editor work and be able to build websites with it. Leveraging JSON Outline Schema, HAX authors multiple pages and writes them onto the file system, so a slim server layer is only needed for basic authentication, saving files, and placing them in version control.

Get all the details at haxtheweb.org.

The ecosystem at a glance

HAX is an ecosystem of many repos. The core three below are what you clone to get started; the rest are listed so you know what's out there.

  • haxcms-nodejs — the Node.js backend for HAXcms (content management + APIs). Usually the fastest way to see HAX running.
  • webcomponents — the heart of HAX: a monorepo of 250+ LitElement web components, themes, and the DDD design system. This is where most component work happens.
  • create (@haxtheweb/create) — the hax CLI for scaffolding web components and HAXsites and managing the dev workflow.
  • haxcms-php (optional) — the PHP backend for HAXcms; same capabilities, different stack (PHP 8.3+ / Apache). For those who prefer the PHP stack.
  • docs — the official documentation site (a HAXcms site itself), at haxtheweb.org.
  • issues — the unified issue queue for the entire ecosystem, plus the canonical onboarding guide.
  • hax11ty, json-outline-schema, hax-schema — supporting repos (11ty integration, content schema, HAX property schema).

Prerequisites

  • OS: macOS or Linux need nothing special. Windows developers should use WSL 2 with Ubuntu (open WSL in the Microsoft Store and select Install/Update, or run wsl --update in PowerShell).
  • Git and a GitHub account (you'll fork repos and open pull requests).
  • Node.js 22 or higher. We recommend fnm as a cross-platform Node version manager (fnm install --lts --use). nvm works too.
  • npm (ships with Node) and yarn (npm install -g yarn) — the webcomponents monorepo uses yarn; the other repos use npm.
  • Windows extra: enable Developer Mode (Windows Settings → For developers → Developer Mode) so symlinks work without running as Administrator. The webcomponents monorepo uses symlinks to emulate a live HAXsite locally.

Contributing conventions

We work primarily with pull requests from forks.

  • Fork the repo you want to contribute to; open a PR pointing at the associated issue.
  • Reference the issue your PR resolves in the PR body (e.g. fixes #123). Do not put @mentions or fixes keywords in commit messages — put them in the PR body.
  • Write clear commit messages; squash small PRs (typos, style) into a single commit.
  • Code style: pure JavaScript (no TypeScript), single quotes, avoid semicolons, use globalThis over window, ES module imports. Code is auto-formatted with Prettier on commit.
  • Web components: use hax webcomponent <name> --y to create new elements (never hand-create elements — the CLI ensures uniform packaging). Adhere to the DDD design system; run hax audit from a component root before submitting.
  • Testing: run yarn test (webcomponents) or npm test per repo before opening a PR.

Migrate Data to HAX

HAX is easy to move content to because it is playing flat HTML files from a simple JSON based data structure. As a result the community has been able to produce a number of atypical migration methodologies. Any system we can teach to serve data in the JSON Outline Schema format that points to HTML, can be migrated to HAX.

DOCX file to website

We can convert .docx files to HTML and then taking the heading hierarchy, pull that in and build structure.

While DOCX import WILL grab images and EVERYTHING IT CAN, images are not recommended for importing. This is because they get imported as base64 content (aka a data blob in the page). This can't be optimized and the only alternative would be for us to scrub images from import (which then you'd be on this page looking anyway..)
Video showing how to use it

HAX to HAX

By pointing to a public HAX site, you can import and remix HAX content in a new space. This is an OER powerhouse made possibly by the specific way HAX stores and manages data.

Notion to HAX

Notion is a great tool for managing the production process. It's a stand alone application popular about media and production teams to complete projects while generating notes and narrative around the process of producing that product. We had a faculty team using Notion to manage the production of an online course prior to deployment. Using a simple HAX import, we are able to take a Notion export and convert it to HAX.

ELMS:LN to HAX

HAX is born out of work in the ELMS: Learning Network ecosystem. The latest version of ELMS:LN effectively runs HAXcms on top of the Drupal based system and as a result can be pointed to and migrated via URL with ease. This integration primarily targets groups internal to Penn State but should work with any ELMS:LN instance.

Import checklist before you start

  • Clean up heading structure first (H1, H2, H3) so the generated outline is accurate.
  • Move large media assets out of authored documents when possible; import text first, then add optimized media back into HAX.
  • Confirm links are valid and absolute before conversion if your source system uses private or relative URLs.
  • Verify attribution and licensing for content you are migrating so remix rights are clear.

Common import paths

Most migrations can be done with either a local file export or a URL-based import. A common command-line pattern is hax site my-site --import-site https://example.com --import-structure htmlToSite --no-i --auto --y and then refining pages after conversion.

  • DOCX to HAX: best for manuscript-style content and quick hierarchy extraction.
  • HAX to HAX: ideal for remixing open content while preserving structure.
  • Notion to HAX: use export bundles and then review embeds/tables after import.
  • ELMS:LN to HAX: strongest path for legacy course migrations from ELMS deployments.
  • Generic HTML to HAX: useful when you can expose source pages publicly and walk them via URL import.

After import: quality pass

Always run a quick editorial pass after migration: verify heading depth, check media load behavior, and confirm that links and callouts are still meaningful in context. For larger sites, pair this with the Reports tutorial so automated link checking catches issues early.

GIF Player

Did you know that the default behavior of the web is to play .gif files automatically if they are added to websites? Did you also know that this is an accessibility issue and disruptive to those prone to motion sickness and other visual imparements? It's also an odd default but unfortunately because of how the web was built, it's one of the few default accessibility issues that exists.

HAX automatically handles GIF files and ensures that they are NOT played by default. It does this by taking a screen shot of the gif (or allowing you to supply one) and then creating an interaction where the user has to click Play on the GIF in order to see it playing. This is a great example of the simple ways that HAX can improve the default accessibility of the web by eliminating the ability for users to cause an accessibility issue in the first place!

Common questions

Where is my content stored?

HAXcms stores pages as plain HTML files in pages/ and the site outline in site.json (JSON Outline Schema). Media lives in files/. Because it's all files, you can version, move, and host them anywhere.

Can I move a site to a different host?

Yes. A HAX site is portable. You can publish via Surge, Netlify, Vercel, GitHub Pages, or any static host, and the hax CLI can rsync a site to a remote directory.

How do I bring in content from Word or a spreadsheet?

Use the import paths in Import Content: DOCX and XLSX import are built in, plus HAX-to-HAX, Notion, ELMS:LN, and generic HTML import via the hax CLI.

Something looks broken — how do I report it?

File it in the issue queue with steps to reproduce. For quick questions, ask in Discord.

For deeper reference while you troubleshoot, browse the Tutorial Library or the Block Reference.

Community pillars reflected this cycle

HAX development is evaluated against seven community pillars. Here is how the 26.8.0 work maps onto them:

  • Accessible: WCAG 2.0 AA components, a11y-media-player transcript support, and video transcript-gap detection so uncaptioned media gets surfaced.
  • Efficient: webcomponents shrank net 8,127 lines through polyfill, Polymer, and wiredjs removal; CLS fixes and lazy loading keep it fast.
  • Free and Open: The on-premises API migration keeps content and calls on your own infrastructure, and OpenStax-to-HAX import extends the 5Rs of OER.
  • Extensible: The Skills framework and an app-store editor make HAX stretch further without forking.
  • Platform Agnostic: PHP and NodeJS backends converged on one v1 REST API, and publish-to-surge, netlify, and vercel reach anywhere.
  • Remixable: Skeleton import/export, docx and EPUB pipelines, and semantic content structures make sites portable and re-mixable.
  • Sustainable: Less data and lower battery use from the net code reduction, web standards over heavy libraries, and inclusive community governance.

Contribute

Learn HAX is built from the HAX network, so the way to improve a tutorial is to improve the network, and the site follows.

How the site is updated

A capability, an element or a doc changes in a HAX repo and its node in the PRAW web is updated.

A two to three minute video and its transcript become a page with screenshots.

The page is added to the outline and published. Every time period shows the new lesson with no extra work.

Web nodes with no tutorial, and tutorials that have gone stale, are listed as candidates.

Two ways to take part

As a user

Follow a tutorial, then tell us where you got stuck. Requests go to the unified issue queue at haxtheweb/issues.

As a contributor

Record a two to three minute tutorial, improve a web node, or build a concept game on the micro game base. Start with Luna, the developer path.

About

Learn HAX is where to learn HAX: tutorials, a reference for every block in the editor, and onboarding for people new to it.

It is made by the HAX project (HAXTheWeb), an open-source effort to let anyone author, remix and publish on the web without needing to learn how the web works. This site is itself a HAX site; its source is on GitHub. Its content is shared under the Creative Commons Attribution-ShareAlike (CC BY-SA) license.

To see how every part of HAX connects, visit hax.cloud. To get in touch, use the Contact page.
