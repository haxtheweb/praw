# hax-ubd-course-design

Understanding by Design for HAX: backward-design a unit end to end (Stages 1-3), author essential questions and GRASPS tasks, map the six facets, classify objectives with Bloom's, and audit existing units.

**Who it is for:** You design courses or units and want backward design built into the workflow.

## Install

```
/plugin marketplace add haxtheweb/praw
/plugin install hax-ubd-course-design@haxtheweb
```

## Skills

| Skill | What it does |
|---|---|
| `hax-ubd-backward-design` | Design a course unit via UbD backward design; emits a unit plan and HAX site skeleton. |
| `hax-ubd-stage1` | UbD Stage 1: big ideas, understandings, essential questions, misconceptions. |
| `hax-ubd-stage2` | UbD Stage 2: evidence scrapbook, GRASPS task, facet rubric, validity self-test. |
| `hax-ubd-stage3` | UbD Stage 3: plan learning experiences via WHERETO. |
| `hax-ubd-essential-questions` | Author essential and entry questions from the six-facet starter bank. |
| `hax-ubd-grasps` | Frame GRASPS performance tasks and pick authentic-context HAX media. |
| `hax-ubd-six-facets` | Write understandings and facet-mapped rubric criteria with the six facets. |
| `hax-ubd-unit-audit` | Read-only UbD review of an existing HAX unit with remediation handoff. |
| `grad-blooms` | Classify learning objectives and design assessments with Bloom's revised taxonomy. |

## Where to start

Start with hax-ubd-backward-design; it orchestrates the stage skills.

## How this plugin is built

The skills live once, in `skills/` at the repo root. This plugin is a curated view over them (the marketplace entry lists the skill paths), so there is nothing to keep in sync here.
